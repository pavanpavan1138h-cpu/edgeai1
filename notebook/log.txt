A. How we calculated trainable parameters

\[

- \(n_{\text{in}}n_{\text{out}}\) = weights
- \(n_{\text{out}}\) = biases
The bias term is included because every output neuron has one bias.

B. How we calculated MACs
A MAC means Multiply–Accumulate operation.

For a dense layer, each output neuron calculates a weighted sum of the inputs. For complexity counting, we count the number of input-weight multiplications:
\[
\boxed{\text{MACs}=n_{\text{in}}\times n_{\text{out}}}
\]

For our 16–16 network:
Layer	Calculation	MACs
Input → Hidden 1	5 × 16	80
Hidden 1 → Hidden 2	16 × 16	256
Hidden 2 → Output	16 × 1	16
Total		352

\[
\boxed{\text{MACs}=80+256+16=352}
\]

Our MAC count is for one forward inference pass and excludes activation-function operations and other overhead. That convention itself must be explicitly stated.

7. All mathematical formulas should be included
Our documentation should have a proper Mathematical Methodology section.
Mean Absolute Error (MAE)
\[
MAE=\frac{1}{N}\sum_{i=1}^{N}|y_i-\hat y_i|
\]

Where:
- \(y_i\) = actual remaining battery life
- \(\hat y_i\) = predicted remaining battery life
- \(N\) = number of evaluated samples
Interpretation: average prediction error measured in days.
Mean Squared Error (MSE)
\[
MSE=\frac{1}{N}\sum_{i=1}^{N}(y_i-\hat y_i)^2
\]

Squared error penalizes larger errors more heavily.
Root Mean Squared Error (RMSE)
\[
RMSE=\sqrt{MSE}
\]

RMSE restores the unit to days, but still gives relatively more weight to large errors.
Median Absolute Error
\[
MedAE=\operatorname{median}(|y_i-\hat y_i|)
\]

This is useful because it describes the central absolute error and is less influenced by a few very large errors.
Mean signed error / bias
Our convention:
\[
\boxed{\text{Bias}=\frac{1}{N}\sum_{i=1}^{N}(\hat y_i-y_i)}
\]

Therefore:
- Positive bias → model tends to overpredict.
- Negative bias → model tends to underpredict.
Low-battery MAE
Our selected low-battery region:
\[
0\leq y_{\text{actual}}\leq10
\]

Then:
\[
MAE_{\text{low}}=
\frac{1}{N_{\text{low}}}
\sum_{i\in\text{low}}|y_i-\hat y_i|
\]

The subset contained 85 validation samples, and it was the same subset for all models because the validation split remained fixed.

This is important: we must explain that the low-battery subset was defined using the actual target values, not the predictions.
